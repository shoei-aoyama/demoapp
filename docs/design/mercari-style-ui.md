# メルカリ風モダンUIへの刷新

## 目的・背景

- 社内デモとしての見栄えを高めるため、既存のシンプルな配色（グレー・黒基調）から、フリマアプリ「メルカリ」を参考にしたモダンな配色・カードデザインへ刷新する。
- 全画面共通のトンマナ変更であり、機能追加は含まない。

## 必要な挙動

- 全画面共通でアクセントカラーに赤系（Tailwindの`red-600`/`red-700`相当）を採用し、主要な操作ボタン（カートに追加・注文手続きへ進む・注文を確定する・ログイン）、ヘッダーロゴ、リンクのホバー状態に適用する。
- 価格表示は黒字の太字を維持し、赤はボタン・アクセントに限定する（価格自体は赤にしない）。
- カードは枠線ではなく余白と控えめな影（`shadow-sm`、ホバー時`shadow-md`）で区切るスタイルに変更する。
- 商品画像は正方形（`aspect-square`）に統一し、`object-cover`でトリミング表示する。
- カートの「販売終了」ラベルは、ブランドの赤と区別するため黒〜濃いグレー基調のバッジに変更する。
- ボタンの角丸は現行の`rounded-lg`を維持する。
- 3列グリッド・画面構成・機能自体は変更しない。

## 受け入れ条件

- [ ] 「カートに追加」「注文手続きへ進む」「注文を確定する」「ログイン」ボタンが赤系アクセントカラーで表示され、ホバー時に色が変化する
- [ ] ヘッダーの「商品注文デモ」ロゴ文字が赤系アクセントカラーで表示される
- [ ] カード/行がボーダーではなく影で区切られ、ホバー時に影が強調される
- [ ] 商品画像が一覧・詳細ともに正方形で表示される
- [ ] 「販売終了」ラベルが黒〜濃いグレー系のバッジで表示され、赤のアクセントと視覚的に区別される
- [ ] 価格表示は黒字の太字のままである
- [ ] 既存の画面構成・機能に変更がない

## 対象外

- 画面構成・レイアウト自体の変更（列数・画面遷移・機能追加）
- ロゴ画像・アイコン等のグラフィック素材の新規作成
- スマートフォン向けのボトムナビゲーション（PCブラウザ前提のため対象外）
- フォント変更

## 制約

- 既存のTailwind CSS（Vite標準構成）の範囲内で実装し、新規ライブラリは導入しない
- 配色はTailwind標準の`red-600`/`red-700`トークンを使用する

## 未決事項

- なし
